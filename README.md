# Telescope

A fast, light file and app launcher for macOS and Windows, written in Rust. "Telescope" is a codename.

Status: milestone M0, the search engine as a command-line tool. The plan is in [docs/research.html](docs/research.html).

## Build

```sh
cargo build --release
cargo test --workspace
```
